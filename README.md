# 대전 서구 동향보고

**https://seogu-brief.vercel.app**

대전광역시 서구청 게시판 다섯 곳을 읽어, 고른 소속(동·부서)과 맞는 건을 앞에 모은
**A4 한 장짜리 목록**을 만들어 주는 도구.

main 브랜치에 푸시하면 Vercel이 자동으로 배포한다.

서구 24개 행정동과 29개 부서 직원이 아침에 게시판을 하나씩 열어 보던 일을 대신한다.

## 화면

- `/` — 소속·기준일·기간을 고르는 페이지
- `/api/report?date=YYYY-MM-DD&days=6&org=월평2동` — 그 조건으로 만든 문서(HTML)

## 만들어지는 문서

소속을 고르면 이런 순서로 나온다. **내용이 있는 표만 싣는다.**

| 순서 | 내용 |
|---|---|
| Ⅰ | `{소속} 사항` — 게시 부서가 우리이거나 제목에 우리 이름이 든 건 |
| Ⅱ | `인근 · 유사 명칭 참고 사항` — 지역명만 겹치는 건 (있을 때만) |
| Ⅲ | `구정 주요 동향` — 수집한 전체, 최신순 |
| Ⅳ | `구 주간행사계획` — 첨부파일 내려받기 링크 (있을 때만) |

월평2동을 고르면 월평1동 공고는 Ⅰ이 아니라 Ⅱ로 간다. 1:1로 맞는 건과
지역만 겹치는 건을 섞으면 무엇이 내 일인지 헷갈리기 때문이다.

**모든 항목의 제목이 서구청 원문 링크다.** 제목만 보고 게시판을 다시 뒤지게 만들면
일을 두 번 시키는 셈이라서. 주간행사계획은 내용이 첨부파일 안에 있어
글이 아니라 한글 파일이 바로 내려받아진다.

## 읽어 오는 게시판

| 게시판 | 상세 링크 방식 |
|---|---|
| 언론보도 · 공지사항 | `view.do?nttId=` (행의 `fn_search_detail` 인자) |
| 고시공고 · 채용공고 | `view.do?notAncmtMgtNo=` (`td[data-key-no]` 값) |
| 주간행사계획 | `/cmm/fms/FileDown.do?atchFileId=` (첨부 직행) |

## 구조

```
index.html        랜딩페이지 (정적)
api/report.js     문서를 만들어 내려주는 서버리스 함수
api/_shared.js    게시판 수집·파싱
api/_org.js       24개 동 / 29개 부서 목록과 소속 매칭 판정
api/_style.js     문서 스타일
```

의존성 없음. Node 런타임의 기본 `fetch`만 쓴다.

## 주의할 점 (고칠 때 읽을 것)

- **동시 접속은 2개까지.** 구청 서버가 3개 이상 동시 요청을 끊는다.
  5개를 한꺼번에 보내면 두 개가 10초쯤 매달렸다가 실패한다.
  순차로 돌리는 편이 오히려 빠르다 (`_shared.js` 의 `pool`).
- **시각은 직접 보정한다.** Vercel은 UTC로 도니 `todayKST()` 로 서울 날짜를 만든다.
- **게시판 구조가 바뀌면** `tbody` 를 못 찾아 그 게시판만 0건이 된다.
  결과의 `failed` 에 이름이 실린다.
- 문서에는 **채워 넣으라고 비워 둔 표를 두지 않는다.** 자동으로 채울 수 없는 칸은
  어느 부서로 열어도 늘 비어 있었고, 빈 표가 붙으면 정작 볼 표를 가린다.
